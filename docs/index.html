GitHub 토큰 입력
마커 추가/삭제는 GitHub에 직접 저장됩니다. 아래 토큰이 필요합니다.
발급 방법:
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: netscomm/WorldRoadTrip 만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate token → 복사 후 아래에 붙여넣기
토큰은 이 페이지 안에서만 사용되고, 새로고침하면 사라집니다.
